# Kota Town Website

## Part 2 – CSS Styling and Responsive Design

Kota Town is a South African street-food website created as a web development project.

### Part 2 updates
- Added an external `style.css` stylesheet.
- Added a CSS reset and consistent typography.
- Added Flexbox navigation.
- Added CSS Grid layouts for services, working hours and the price list.
- Added hover and focus pseudo-classes.
- Added responsive images.
- Added tablet and mobile breakpoints using media queries.
- Added the viewport meta tag to all HTML pages.
- Improved form styling and accessibility with labels and image alt text.

### Pages
- `Index.html` – Home
- `About.html` – About Kota Town
- `Services.html` – Services
- `Gallery.html` – Price List
- `Contact.html` – Contact and ordering
